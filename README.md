# Superstore Sales & Profitability Analysis

SQL + Tableau project analyzing sales, profit, and discount trends from the Superstore dataset to identify profitability issues by region, category, and sub-category.

## 🔗 Live Dashboard

[View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/rishith.arava/viz/SuperstoreSalesProfitabilityAnalysis_17846260177930/Dashboard1)

## Tools Used

- MySQL (data cleaning, aggregation queries)
- Tableau Public (interactive dashboard)

## Key Insights

- West region generates the highest profit; Central lags behind
- Tables and Bookcases sub-categories operate at a loss despite steady sales
- High discounting (20%+) correlates strongly with reduced/negative profit in Furniture and Office Supplies
